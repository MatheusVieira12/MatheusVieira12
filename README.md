## 🚀 Projetos em destaque

### [MVP – Engenharia de Dados | Segurança Pública do RJ](https://github.com/MatheusVieira12/mvp-engenharia-dados-seguranca-rj)
Pipeline de dados desenvolvido com Databricks e PySpark a partir de bases públicas do Instituto de Segurança Pública do Rio de Janeiro (ISP-RJ).

- Implementação da Arquitetura Medalhão: Bronze, Silver e Gold.
- Ingestão, tratamento, padronização e validação de dados.
- Armazenamento em Delta Lake e organização de tabelas.
- Modelagem dimensional e construção de indicadores para análises de segurança pública.

**Tecnologias:** Databricks, Python, PySpark, Delta Lake e SQL.

### [Projeto NARA – Banco de Dados e BI](https://github.com/MatheusVieira12/Projeto_Nara)
Projeto de estruturação de banco de dados relacional para organizar informações de clientes, produtos, vendas, campanhas, atendimentos e avaliações.

- Modelagem de tabelas e relacionamentos com chaves primárias e estrangeiras.
- Criação de scripts SQL para estruturação e carga de dados CSV.
- Preparação das informações para análises e visualizações no Power BI.

**Tecnologias:** MySQL, SQL e Power BI.

### [Análise de Dados – Segurança Pública](https://github.com/MatheusVieira12/Repo_Senac)
Projeto acadêmico de análise exploratória de dados públicos de segurança do Rio de Janeiro.

- Análise de ocorrências por delegacia, circunscrição e região.
- Aplicação de estatística descritiva e identificação de valores atípicos com IQR.
- Análises comparativas e visualização de padrões criminais.
- Exportação de resultados tratados para arquivos CSV.

**Tecnologias:** Python, Pandas, NumPy, Matplotlib e Jupyter Notebook.

### TCC – Automação e agentes de IA
Desenvolvimento de workflows no n8n com agentes de IA para automatizar a coleta de informações em sites e apoiar a pesquisa e produção de artigos.

**Tecnologias:** n8n, agentes de IA e automação de workflows.
